1. HOW TO OPEN AND PRESENT OFFLINE
--------------------------------------------------------------------------------
1. Unzip the project folder to any local directory on your computer.
2. Double-click `index.html` to open it in any modern web browser (Google Chrome,
   Microsoft Edge, Mozilla Firefox, or Safari).
3. No internet connection, local server, external font, or third-party library
   is required. Everything runs 100% offline.
4. For classroom projection, press `F11` (Windows/Linux) or `Ctrl + Cmd + F`
   (macOS) to enter full-screen browser mode.

--------------------------------------------------------------------------------
2. PRESENTATION NAVIGATION & KEYBOARD CONTROLS
--------------------------------------------------------------------------------
- Cover Screen: Click the "Let's Explore" button (or press `ArrowRight`) to
  enter the 10-section presentation. Click the top-left AIBL brand badge at any
  time to return to the Cover Screen.
- Top Navigation Bar: Click any of the 10 tabs (`1. Layout`, `2. Products`,
  `3. Experience`, `4. Loan Case`, `5. Careers`, `6. Hospitality`, `7. NPL`,
  `8. Management`, `9. Notes`, `10. Contact`) to open that section immediately.
- Keyboard Shortcuts:
  * `ArrowRight` : Advance to the next tab
  * `ArrowLeft`  : Return to the previous tab
  * `Home`       : Jump to the first tab (`1. Layout`)
  * `End`        : Jump to the last tab (`10. Contact`)
  * `Escape`     : Close an open image lightbox modal
- Note: Per presentation design requirements, no floating or on-screen previous/
  next arrow buttons are displayed anywhere.
- Image Lightbox: Click any "Enlarge Image" button beneath a photograph or
  document scan to inspect it in high resolution.
